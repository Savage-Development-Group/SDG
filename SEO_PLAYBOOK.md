# Savage Dev Group SEO launch and growth playbook

The website now contains the technical foundation, landing pages, case study, and first six-article content cycle. The remaining tasks require access to third-party accounts or real business details and should be completed at launch.

## Search engine setup

1. Add `savagedevgroup.com` as a Domain property in Google Search Console.
2. Add the DNS TXT verification record supplied by Google.
3. Submit `https://savagedevgroup.com/sitemap.xml` in Search Console.
4. Inspect the homepage, three service pages, and Task Forge case study; request indexing after the deployed pages are reachable.
5. Connect Search Console to the analytics property used for SDG reporting.
6. Repeat verification and sitemap submission in Bing Webmaster Tools.

## Business identity and local search

Only create location signals that are true and supportable.

- If SDG serves customers from an eligible staffed location, create or complete a Google Business Profile using the real business name, phone, hours, category, and service area.
- Keep the business name, address/service area, phone, URL, and description consistent across authoritative profiles.
- Add verified LinkedIn and other active business profiles to the Organization schema `sameAs` list.
- Add a real phone number and service location to the site only when SDG wants them public.

## Measurement

Track these outcomes separately from general page views:

- Contact form submitted
- Contact page reached from a service page
- Task Forge case study viewed
- Task Forge outbound visit
- Qualified organic landing sessions by service page
- Search queries and pages producing inquiries

Review Search Console monthly for indexing, query impressions, click-through rate, page growth, and rich-result issues. Review analytics for conversion rate by landing page and acquisition source.

## Six-article publishing sequence

The initial articles are complete. Publish or promote them in this order so each supports an existing commercial page:

1. Small-business website checklist → Website Development
2. Custom web app vs. off-the-shelf software → Web Application Development
3. How contractor software reduces administrative work → Task Forge OS case study
4. What does a custom business website cost? → Website Development / Contact
5. E-commerce platform vs. custom storefront → E-commerce Development
6. How SDG approached Task Forge OS → Task Forge OS case study

After launch, space promotion across approximately twelve weeks. Refresh dates only when an article receives a meaningful update.

## Authority building

Prioritize relevant, earned references instead of bulk directory submissions.

1. Add the SDG URL and case-study links to maintained GitHub project descriptions and documentation.
2. Create complete company and founder profiles on the professional networks SDG will actively maintain.
3. Ask real clients or collaborators for permission to publish detailed case studies and link to them from their sites when useful to their audience.
4. Join the relevant local chamber or credible regional business association if SDG is pursuing local work.
5. Submit Task Forge OS to appropriate contractor-technology and software directories with consistent product information.
6. Contribute practical articles, interviews, or examples to trade and small-business publications where SDG has genuine expertise.

Avoid paid link packages, mass guest posting, copied location pages, fabricated reviews, and directories created only to sell links.

## Quarterly maintenance

- Check every sitemap URL for a successful response, canonical tag, unique title, unique description, and one H1.
- Run mobile performance tests on the homepage and primary landing pages.
- Review broken links, image sizes, form delivery, privacy text, and structured-data validation.
- Improve pages already receiving impressions before creating loosely related content.
- Add measured outcomes and verified testimonials as they become available.
