# Savage Dev Group

Static portfolio site for [savagedevgroup.com](https://savagedevgroup.com), ready for GitHub Pages.

## Local preview

Open `index.html` directly, or run any static file server from this folder.

## Contact form

The form uses FormSubmit's free static-site endpoint. The first test submission sends a one-time activation message to the configured recipient; approve it before expecting inquiries to be delivered.

## GitHub Pages

Publish from the repository's `main` branch at `/ (root)`. The included `CNAME` configures the custom domain.
